**NOTE: Major changes incoming to the public API - this package will become a wrapper for the GeochemistryTools ecosystem - all example code from publication will be made compatible with the changes**

GeochemistryTools.jl is an *in-development* [Julia](https://julialang.org/) package for geochronological and geochemical research.

Functionality is influenced by [IsoplotR](https://github.com/pvermees/IsoplotR) and [global_geochemistry (MATLAB)](https://github.com/dhasterok/global_geochemistry).

This package is not listed in the Julia repo yet as significant changes to improve the modularity and maintainability are incoming.

For now, if you would like to try add it to your Julia project to use the provided features:

First enter Pkg REPL in your Julia REPL by pressing `]` then

```julia
add "https://github.com/jarredclloyd/GeochemistryTools.jl"
```
